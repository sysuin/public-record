# Public Record

Questions people argue about, settled with data anyone can download. A series by [Sartium](https://sartium.com).

Every report follows the same rules:

- **Primary sources only.** Each figure traces to a dataset published by the body that produced it.
- **The claim never travels further than the data.** If the evidence covers one city, one league or one year, the report says so.
- **What the data cannot tell you is part of every report**, not a footnote.
- **Everything is reproducible.** Each report folder holds the scripts, the derived data, the research file and the exclusion log.
